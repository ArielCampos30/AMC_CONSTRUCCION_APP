# Landing AMC

Primera landing pública de AMC Construcciones y Arreglos.

## Antes de publicarla

1. Abrir `docs/index.html`.
2. Buscar `const WHATSAPP_NUMBER = "";`.
3. Colocar el número de WhatsApp Business completo, con código de país, sin signos, espacios ni guiones.
4. Reemplazar/añadir fotos reales de trabajos cuando estén disponibles.
5. Revisar nombre comercial definitivo y zonas de cobertura.

## Publicación simple

El archivo está pensado para poder publicarse como sitio estático. Una opción gratuita es GitHub Pages usando la carpeta `/docs` de la rama principal una vez que estos cambios sean aprobados y mezclados.

AMC PRESUPUESTOS - PROYECTO ANDROID 1.0.0

Este proyecto envuelve la web app V5 dentro de una aplicación Android nativa.

Incluye:
- Mis trabajos: alta, edición y baja de trabajos/precios propios.
- Tarifario editable.
- Presupuestos múltiples y guardados.
- Recomendación m²/unidad vs jornal.
- PDF con logo y renglones profesionales.
- PDF guardado por Android en Descargas/AMC Presupuestos.
- Compartir PDF con el menú nativo del teléfono.

Firma y futuras actualizaciones:
- applicationId fijo: com.amc.construcciones
- el APK oficial se firma con la clave privada AMC.
- conservar esa clave es imprescindible para instalar futuras versiones encima de la anterior.
